Design reference: The 13 legacy LeetCollab screenshots define the prototype's visual direction: compact headers, teal diamond mark, monochrome primary actions, slate/white surfaces, restrained borders, softly elevated panels, and a dense editor-room layout in light and dark themes. This mockup is not the final system implementation; the production app is intended to use actual Shadcn/ui components. All approved page content and flow are retained.

Scope boundary: The shared editor, chat, whiteboard, timer, participants, and room credentials build on the existing collaboration foundation. The dashboard, compact problem library, single Answer flow, submission history, personal grades, suggested dates, and progress view are proposed additions. Every result shown here is simulated. The selected plan uses a LeetCollab-owned judge through an external sandbox while shared app quota is available, then offers source-linked fallback only for a problem with a valid source judge; that external result is not LeetCollab-verified.
